# ANATOMAI UI 7.8 — Visual Refinement & iOS UX Fixes

## Основа и диагностика

Ветка: `redesign/anatomai-ui-7.8`. Основа — UI 7.7, PR #19, коммит `101b7c69c98ecf93e87a42340b842be0b981772a`, а не `main`.

Перед изменениями изучены HomePage, TopicPage, StatisticsPage, ProfilePage, TestSession, TestResult, AppShell, Telegram adapter, viewport и zoom lock.

Установлено:

- `overscroll-behavior: contain` предотвращал передачу прокрутки, но разрешал локальный эффект границы. Документ не был явно закрыт для прокрутки. Поздно подключаемый `viewport.css` также перекрывал правило основного контейнера. Это подтверждённые недостатки CSS; они сами по себе не доказывают точную причину нативного оттягивания Telegram iOS.
- Обычно прокруткой управляет `.shell__content`; в тестовом потоке внешний контейнер закрыт, а тема, статистика, результат и центр вопроса прокручиваются самостоятельно. Эта архитектура сохранена.
- Динамическая высота уже учитывает Telegram viewport, visual viewport и клавиатуру. Safe-area уже вычисляется адаптером; дополнительных отступов и второго расчёта не требуется.
- Zoom lock не блокирует обычный одноточечный `touchmove`. Глобальный блокировщик прокрутки не добавлен.
- Главная показывала демонстрационные XP, серию, средний результат, время, недельные столбцы и прогресс предметов. Они не были связаны с историей тестов.
- Имя профиля выбиралось из launch data раньше `initDataUnsafe.user`, даже когда SDK содержал другое актуальное имя. Не было нормализации Unicode.
- История существует только в состоянии React: до 100 последних завершений текущего запуска. Нет серверной синхронизации, постоянного хранилища истории, XP/уровней и хранилища избранного. Реальные условия достижений вычисляются существующим модулем; не реализованные условия остаются закрытыми.

## Реализация

### Прокрутка и геометрия

Документ и root закрыты для прокрутки. Существующие вертикальные владельцы используют `overscroll-behavior-y: none`; основной стиль исправлен непосредственно в `viewport.css`. Карусель сохраняет горизонтальную прокрутку и CSS scroll-snap, вертикальный жест может прокручивать родителя. Не изменены Telegram adapter, BackButton, zoom lock, алгоритм safe-area, нижняя навигация и обработка клавиатуры.

Это прогрессивное CSS-ограничение эффекта границ. Реальный Telegram iOS не запускался: устранение нативного rubber-band не заявляется.

### Главная

Сохранены композиция, hero, кнопка запуска, разделы и четыре вкладки. Hero и карусель уплотнены. Демо-показатели больше не отображаются: средний результат, время практики и активность берутся из завершений текущего запуска; без результатов показаны `—`, ноль и пустые столбцы. XP явно недоступны. Серия вычисляется существующим модулем по реальной истории либо показана как неизвестная. Предметы показывают количество вопросов каталога вместо демонстрационного личного прогресса. Шапка использует доступное Telegram-имя и текущую дату, с нейтральным fallback.

### Тема и статистика

На теме три показателя: вопросы, лучший результат, ошибки. По умолчанию видны первые три вопроса, доступно раскрытие всех и сворачивание. Убраны неработающие элементы избранного. Предпросмотр не отмечает правильные ответы.

В статистике две основные карточки, компактная недельная активность, история и раскрываемые достижения/объяснение. Большая синяя заглушка удалена. Ограничение истории текущим запуском и отсутствие XP/синхронизации явно указаны.

### Профиль и вопрос

Общий hook читает отображаемую личность только при подтверждённом Telegram-контексте существующего адаптера. Приоритет имеет SDK `initDataUnsafe.user`, launch data используются как fallback. Имя нормализуется в NFC; длинные имена переносятся, в браузере используется нейтральный профиль. Эти данные используются для отображения, не для авторизации.

Premium сохраняет тёмно-синюю/золотую палитру, стал компактнее. «Подробнее» открывает существующее честное информационное окно. Сброс доступен только внутри настроек, при наличии результатов и после подтверждения; отмена сохраняет историю. Недоступные настройки и уведомления остаются явно обозначены.

На вопросе «Пропустить» слева, основное действие справа. Кнопки остаются на месте: основное действие отключено до выбора/проверки; пропуск отключён после проверки в обучении. Уменьшены промежутки заголовка. Не изменены движок, оценка, вопросы, ответы, результаты и повтор ошибок.

## Ограничения и проверка на устройстве

Нужен реальный iPhone с Telegram: медленный и резкий свайп на обеих границах, горизонтальный/диагональный жест карусели, expanded/fullscreen, поиск с настоящей клавиатурой, возврат/повторное открытие Mini App. Mock SDK подтверждает обработку API в приложении, но не поведение системного UI клиента. Chromium не проверяет WebKit, нативный bounce и реальную Telegram-панель.

Данные SDK не проверяются сервером в рамках этой задачи. История, серия и достижения ограничены сохранёнными в памяти результатами; перезагрузка или сброс очищает их. XP, избранное, серверная история и платежи не внедрялись.

## Откат

Изменения оформляются одним коммитом поверх `101b7c6`. Для отката выполнить `git revert <коммит UI 7.8>` в отдельной ветке и проверить typecheck/tests/build. Базовая версия доступна в `redesign/anatomai-ui-7.7`. Миграций и изменений backend нет. Автоматический merge, deploy и изменения MEDEXA/production не выполнялись.
