# ANATOMAI — Home Layout 8.0

Ветка: `feature/anatomai-home-layout-8.0`, создана от `f1a264998803a1000215a6dc327631db869f62b6` (UI 7.9 Compact 2.0).

Учтено последнее уточнение пользователя: **статистику оставить, убрать только недельную активность на Главной**. Средний результат, время практики и «Подробнее» сохранены.

## Итоговый порядок

1. Шапка и приветствие.
2. «Твой фокус на сегодня».
3. «Предметы» — сразу после фокуса.
4. «Повтори сегодня» — сразу после предметов.
5. «Твоя статистика» — две прежние карточки и «Подробнее».
6. Промокарусель.
7. «Совет на сегодня» — непосредственно после карусели, последний блок.

У недельного блока StatisticsSection появился необязательный параметр `showActivity` с прежним значением `true` по умолчанию. Только HomePage передаёт `false`. Расчёты, данные и существующие компоненты не удалялись. Недельная активность на отдельном экране статистики сохранена; «Подробнее» по-прежнему открывает этот экран.

Дизайн предметов и повторения, шапка, Hero, статистические карточки и нижняя навигация не менялись. Промокарусель сохранила стили Compact 2.0: высота 110–115 px, ширина 78–82%, скругление 16 px, все четыре действия, свайпы и согласованное оформление Premium. Исходные WebP побайтно сохранены. CSS, safe-area, нижний резерв контента, Telegram SDK, backend, тестовый движок, конспекты и профиль не изменены.

## Изменённые файлы

- `src/pages/HomePage.tsx` — перестановка существующих блоков; скрытие недельной активности только на Главной.
- `src/components/StatisticsSection.tsx` — опциональный показ недельного графика, без изменения статистических расчётов.
- `tests/ui79.mjs` — новый порядок, сохранённая статистика/переход «Подробнее», отсутствие недельного блока на Главной и отступ совета от навигации.
- `docs/home-layout-8.0.md` — отчёт.
- `docs/screenshots/home-layout-8.0/*` — мобильные экраны и снимки карусели.

## Ограничения и откат

Реальные iPhone, Telegram iOS и Safari/WebKit не запускались; нативные жесты и поведение клиента требуют проверки на устройстве. В рамках этой задачи не менялись прежние демонстрационные подписи существующей карточки «Повтори сегодня» — её содержимое и функции сохранены по требованию пользователя.

Для отката выполнить `git revert <коммит Home Layout 8.0>` в отдельной ветке. Main, работающий Preview, MEDEXA и production не изменялись. Merge и deploy не выполнялись.
