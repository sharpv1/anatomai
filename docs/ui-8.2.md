# ANATOMAI UI 8.2 — UX Refinement

Ветка: `feature/anatomai-ux-8.2`, основа — `165e7b65e9d08e35d2e69dcbe4ddba414e831eac` (утверждённый UI 8.1). Main, backend и опубликованный Preview не изменялись.

## Диагностика источников

- `catalog` и `disciplines` уже построены из существующих определений тестов; реальные количества вопросов берутся через `questionsForTest`. ID дисциплины совпадает с ID соответствующей темы/теста: `anatomy`, `physiology`, `neuro`, `histology`.
- Три визуальные карточки Главной раньше связывались с названием дисциплины и не имели рабочего перехода. Теперь они содержат явные канонические ID; дизайн сохранён.
- История завершений — существующий React state, максимум 100 попыток текущего запуска. Серверной или постоянной истории нет. Средний результат берётся из прежнего `summarizeHistory`, длительность — из существующих результатов попыток.
- Страница конспектов раньше хранила выбранную дисциплину локально. Теперь выбор передаётся существующему компоненту через App и history, чтобы поддержать прямой вход с Главной и правильный возврат.
- Вопросы дня используют тот же каталог и банк, что «Ответы и разбор». Второго банка, искусственных вопросов и нового движка нет.

## Реализация A–F

### A. Статистика Главной

Заголовок «Твоя статистика» и «Подробнее» сохранены. Вместо двух отдельных больших карточек — одна горизонтальная карточка из трёх показателей: завершено тестов, средний результат, время практики.

Ноль завершений — достоверный счётчик текущего запуска; без завершений средний результат и время показаны как `—`. Время — сумма длительностей завершённых попыток, не время нахождения в приложении. Если длительность некорректна/не задана, выводится `—`. Под блоком указано «Текущая сессия», поэтому ноль не выдаётся за общую серверную статистику пользователя.

### B. Предметы и конспекты

Каждая карточка открывает существующую дисциплину конспектов по ID. «Все» открывает каталог конспектов. Материалы не выдумываются: в текущем проекте дисциплины показывают честное пустое состояние.

Прямой переход Главная → дисциплина возвращает на Главную. Переход Главная → каталог → дисциплина возвращает сначала в каталог, затем на Главную. Обычный вход через вкладку «Конспекты» сохраняет возврат из дисциплины в каталог. Работают browser history и существующий Telegram BackButton; подписка неактивного экрана отключена, внутренний возврат в Telegram не дублируется.

Новые history-записи содержат только маршрут, канонический ID и источник возврата. При восстановлении проверяется существование ID в текущем каталоге. Это навигационные метаданные, не параллельная система данных.

### C. Вопросы дня

Прежняя демонстрационная карточка «Повтори сегодня» заменена «Вопросами дня» из существующего банка. Показаны дисциплина, тема и фактическое количество вопросов. Вся карточка открывает «Ответы и разбор» этой темы; возврат ведёт непосредственно на Главную, без промежуточной страницы теста.

Выбор детерминирован: доступны только темы с вопросами, ID сортируются стабильно, индекс определяется номером локального календарного дня. Порядок исходного массива и время внутри одного дня не меняют рекомендацию. Перезагрузка с тем же банком даёт ту же тему. Локальные компоненты даты используются вместо UTC-даты; переход летнего времени учтён при планировании следующего обновления. Рекомендация обновляется при локальной полуночи и возвращении приложения в фокус. При изменении самого набора доступных ID результат может измениться — это не пользовательская статистика и не постоянное назначение с сервера.

Если доступных тем нет, показано пустое состояние без активной кнопки. Просмотр вопросов не создаёт завершённую попытку и не изменяет статистику.

### D. Ответы и разбор

Название заменено во всех текущих пользовательских заголовках и переходах. Уплотнены шапка, интервалы карточек и вариантов; доступная подпись поиска сохранена для screen reader. Все варианты и правильные ответы видны сразу, зелёная подсветка и объяснения прежние. Сохранены поиск, исходная нумерация, длинные тексты, порции по 30 карточек и поддержка явных нескольких правильных индексов в read-only модели.

Реальный банк по-прежнему содержит один правильный индекс. Множественные ответы и большой банк проверяются на изолированных фикстурах; данные приложения и тестовый движок не менялись.

### E. Тема в тестах

Удалены «Вопросы темы», встроенный предпросмотр и «Показать все». Оставлена одна строка «Ответы и разбор». Статистика темы сохранена.

Разметка, классы, подписи и onClick кнопок «Обучение» / «Экзамен», а также `startTopic`, побайтно совпадают с `165e7b6`. CSS этих кнопок не менялся. UI-проверка сравнивает их реальные координаты, размеры, вычисленные стили и пиксели при одинаковых координатах снимка. Справочник размонтируется в экзамене; правильные ответы до завершения не раскрываются.

### F. Premium профиля

Тёмная карточка заменена светлой компактной строкой с лавандовым акцентом, небольшой короной, названием «ANATOMAI Premium», подписью «Расширенные возможности — скоро» и стрелкой справа. Нажатие открывает прежнее информационное окно, без оплаты, цен и подписки. Остальные элементы профиля не менялись, включая содержимое существующего меню.

## Ограничения и откат

Реальный iPhone / Telegram iOS / Safari WebKit не запускались. На устройстве нужны проверки BackButton, клавиатуры поиска, фонового восстановления и нативной прокрутки. Mock API не подтверждает поведение системного интерфейса клиента.

Постоянная серверная история, материалы конспектов, избранное и платежи отсутствуют; эти функции не имитируются. История попыток остаётся только в памяти текущего запуска. WebP, тестовый банк, алгоритм оценки, API, Telegram SDK и backend не менялись.

Для отката — `git revert <коммит UI 8.2>` в отдельной ветке. Merge, deploy, изменения main, работающего Preview, MEDEXA и production не выполнялись.
