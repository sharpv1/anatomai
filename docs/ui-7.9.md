# ANATOMAI UI 7.9 — интеграция промобаннеров

Основа: `redesign/anatomai-ui-7.8`, коммит `bf0e5a6df120849769ab46f605977393ee088d79`, PR #20. Новая ветка: `redesign/anatomai-ui-7.9`.

## Реализация

В проекте Vite находится в корне репозитория, папки `app/` нет. Три исходных изображения из `anatomai-promo-banners.zip` размещены в `public/promos/` без изменения байтов:

| Изображение | Баннер | Переход |
| --- | --- | --- |
| `promo-tests.png` | Синий: «Проверь свои знания» | Существующий каталог тестов |
| `promo-notes.png` | Зелёный: «Повторяй главное» | Существующая вкладка конспектов |
| `promo-exams.png` | Фиолетовый: «Готовься к экзаменам» | Существующий каталог тестов, согласно уточнению пользователя |

Использован существующий `StudyPromos`. Второй карусели, дополнительных текстовых наложений, нового экрана экзаменов и нового тестового движка нет. Выбор дисциплины и режима продолжает работать через существующий каталог.

Сохранены scroll-snap, частично видимая следующая карточка, горизонтальные жесты и возможность вертикальной прокрутки родителя. Нет автопрокрутки, глобального блокировщика touchmove или изменений Telegram SDK. Оформление картинок ограничено классом `.study-promo--image`; общие токены, Hero, статистика, дисциплины, профиль и нижняя навигация не изменены.

Изображения имеют одинаковые исходные размеры 1774×887 (2:1). Соотношение сторон кнопки и атрибуты `width`/`height` резервируют высоту до загрузки. `object-fit: contain` показывает изображение целиком; исходные белые поля и медицинские объекты сохранены. Скругление — 20 px. Высота зависит от ширины, фиксированной обрезки нет.

Кнопки имеют доступные русские подписи назначения и существующее оформление keyboard focus. Изображения с пустым `alt` не дублируют подпись кнопки. Используются `loading="lazy"`, `decoding="async"`, путь с учётом `BASE_URL` Vite.

Удалено ставшее неиспользуемым открытие Home Premium: третья карточка теперь ведёт в тесты. Информационное окно Premium в профиле сохранено и проверено.

## Ограничения

Настоящие Telegram iOS, Safari/WebKit, системные жесты и нативный rubber-band не проверялись. Требуется проверка на iPhone; отсутствие нативного bounce не заявляется. Существующие ограничения scroll-контейнеров UI 7.8 сохранены.

Оригинальные PNG весят суммарно 5 267 865 байт (~5.02 MiB). Они не перекодированы. Lazy loading разрешает браузеру загружать соседние изображения заранее; количество немедленных запросов определяет браузер. При медленной сети загрузка может занять время, но зарезервированная геометрия сохраняется.

Merge, deploy, изменения сервера, backend, MEDEXA и production не выполнялись. Для отката — `git revert <коммит UI 7.9>` в отдельной ветке; UI 7.8 остаётся базой, миграций нет.
