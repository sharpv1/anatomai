Ветка: `redesign/anatomai-ui-7.9`. Обновление существующего Draft PR #21 поверх `0b5343f`; новый PR не создаётся. База всего PR — UI 7.8 / `bf0e5a6`.

## Источники и окончательный порядок

Использованы исключительно четыре изображения из предоставленного пользователем архива **ANATOMAI-approved-banners.zip**. Новые изображения не генерировались. Последнее уточнение пользователя задаёт порядок: **Подготовка к экзаменам → Конспекты → Повторение ошибок → Premium**.

| № | Файл в архиве | Файл в public/promos/ | Нажатие |
| --- | --- | --- | --- |
| 1 | `exams.jpeg` | `exam-preparation.webp` | Существующая вкладка тестов |
| 2 | `notes.jpeg` | `medical-notes.webp` | Существующая вкладка конспектов |
| 3 | `mistakes.jpeg` | `mistake-review.webp` | Информация о недоступности отдельного режима повторения ошибок |
| 4 | `premium.jpeg` | `anatomai-premium.webp` | Существующее окно «Premium скоро появится» |

Все исходники имеют размер 1536×768 (2:1). Выполнено только сжатие в WebP, Pillow quality=92, method=6: без масштабирования, обрезки, изменения надписей, перестановки объектов или CSS-иллюстраций. Белые поля исходников сохранены. Суммарный размер: 787 450 → 307 730 байт (−60.9%); по сравнению с прежними тремя PNG — −94.2%.

[Файл происхождения изображений](approved-promos-provenance.json) фиксирует SHA-256 архива, каждого входного JPEG и выходного WebP, размеры и параметры преобразования. В `dist/promos/` включены те же байты WebP, что в `public/promos/`. Три старых PNG с торсами удалены из приложения; старые скриншоты заменены актуальными.

## Компонент и переходы

Использован существующий `StudyPromos`, ровно четыре баннера. Сохранены CSS scroll-snap, частично видимая соседняя карточка, скругления 20 px, отсутствие автопрокрутки и вертикальная прокрутка родителя. Изображения целиком помещаются через `object-fit: contain`, без текстовых наложений. Атрибуты 1536×768 и существующее `aspect-ratio: 2 / 1` резервируют высоту до загрузки. Сохранены lazy loading, async decoding, доступные подписи кнопок, keyboard focus и путь с учётом Vite BASE_URL.

В приложении есть **разбор ответов после результата**, но нет отдельного общего режима повторения ошибок. Поэтому третий баннер честно сообщает: «Повторение ошибок пока недоступно. Отдельный режим повторения ошибок пока не реализован. Разбор ошибок доступен после завершения теста на экране результата». Фиктивная страница и второй движок не создавались.

Оба информационных окна переиспользуют существующий `PremiumDialog`, включая существующий hook возврата. Открытие записывает состояние в browser history; «Понятно», браузерный возврат и mock Telegram BackButton закрывают окно. Повторное открытие не накапливает callbacks. Premium не предлагает фиктивной оплаты.

Hero, шапка, статистика, дисциплины, профиль, нижняя навигация, тестовый движок и Telegram SDK не изменены этим исправлением. Параметры safe-area и владельцы прокрутки сохранены.

## Ограничения и откат

Реальные iPhone, Telegram iOS и Safari/WebKit не запускались. Нативный bounce и системные жесты требуют проверки на устройстве; их устранение не заявляется. Lazy loading позволяет браузеру заранее загружать соседние карточки. Мелкие подписи внутри готового изображения конспектов масштабируются вместе со всем баннером; текст и композиция намеренно не переделывались.

Merge, deploy, изменения backend, сервера, MEDEXA и production не выполнялись. Для отката только этой замены — `git revert <коммит утверждённых баннеров>` в отдельной ветке (вернёт прежние варианты PR #21). Для возврата всего интерфейса к UI 7.8 нужно откатить оба коммита PR #21. Миграций нет.
