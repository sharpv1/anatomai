Ветка: `fix/anatomai-scrollbars-8.3.2`. Основа — актуальная на момент проверки ветка UI 8.3 в GitHub, `8091155f914240e7133b4c17d6b520db4c1fb8cd`. Рабочая копия была чистой; main и опубликованный Preview не изменялись.

В исходниках также есть внешние clipping-контейнеры с `overflow: hidden`; они не превращались в scroller и не менялись. Определений `overflow: scroll` не обнаружено; общее правило подходит и для таких будущих контейнеров. Короткое содержимое не всегда переполняет свой контейнер — это штатное поведение.

## Изменение

Добавлен единый `src/styles/scrollbars.css`, импортируемый AppShell. Политика ограничена `.shell` и её DOM-потомками, включая вложенные scroller и top-layer dialog:

- `scrollbar-width: none`;
- `-ms-overflow-style: none`;
- `::-webkit-scrollbar { display: none; width: 0; height: 0; }`.

Новые правила не задают overflow, размеры карточек, отступы, цвета, touch-action, safe-area или scrollbar-gutter. Старые разрозненные правила из motion.css и карусели удалены. Скрытие индикаторов теперь находится в одном месте и не требует CSS на каждой странице.
