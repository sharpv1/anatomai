# ANATOMAI UI 8.3 — Compact Daily Questions & Test Cleanup

Ветка: `fix/anatomai-ui-8.3`, создана от `da561b71e60766de171c4750a39fb0b3f75aec8c` (UI 8.2). Main, опубликованный Preview и backend не изменялись.

## Реализация

### Компактные вопросы дня

Отдельный крупный заголовок убран. Существующая карточка стала горизонтальной высотой **86 CSS px**, с маленькой иконкой, дисциплиной, названием темы, фактическим количеством вопросов и стрелкой. Внутренние интервалы уменьшены, длинная тема ограничена двумя строками; полное название остаётся в `title`, доступном имени кнопки и открываемом справочнике. Пустой банк по-прежнему показывает состояние без активной кнопки.

Ежедневный селектор, сортировка ID, локальная календарная дата, обновление на полуночи/при восстановлении приложения и переход в «Ответы и разбор» сохранены без изменений. Новые вопросы и данные не создавались.

### Тестирование и результат

В обучении больше не выводится блок медицинского объяснения после ответа. Сохранены прежние зелёная/красная подсветка карточек, галочки, блокировка проверенного ответа, счётчик правильных, прогресс, серии и кнопки действий. Краткий статус правильности сохранён для screen reader, без видимого объясняющего блока.

В экзамене объяснений и раскрытия правильных ответов нет. Проверка, подсчёт, пропуски, завершение и таймер не менялись.

Диагностика показала, что `TestResult.tsx` уже не отображает `question.explanation`; файл оставлен неизменным. Сохранён существующий разбор ошибок/пропусков: текст вопроса, выбранный и правильный ответы. Это не текстовое объяснение. Повторное прохождение и возврат к тестам работают как прежде.

Разметка, подписи, классы и onClick кнопок выбора режима — и на странице темы, и в существующем выборе режима TestSession — побайтно совпадают с UI 8.2. Их CSS и обработчики не менялись.

### Ответы и разбор

Удалены раскрываемые объяснения и их неиспользуемые стили. Все варианты остаются видны сразу, правильные выделены зелёным. Поиск, нумерация, загрузка порциями, множественные правильные индексы в read-only модели и возврат сохранены. Поля объяснений в исходных данных не удалены и не изменены.
