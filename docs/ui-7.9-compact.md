# ANATOMAI UI 7.9 — компактная промокарусель

Ветка: `fix/anatomai-ui-7.9-compact-promos`, создана непосредственно от `6ad36df0abc7400b219f7369e69adcb6b31bdbaf`. Изменение изолировано от main и ветки PR #21. Работающий сервер и опубликованный Preview не изменялись.

## Причина и исправление

У кнопок уже были нулевые padding и border. Большая часть пустоты находилась непосредственно в четырёх WebP: исходный холст 1536×768 включает светлые внешние поля. `object-fit: contain` показывал их целиком, а `aspect-ratio: 2/1` задавал высоту карточек 155.5 / 163 / 183 px при ширинах экрана 375 / 390 / 430 px.

Карточка теперь имеет `height: clamp(140px, 36vw, 150px)`, `overflow: hidden`, радиус 20 px, нулевые margin/padding/border. При тех же ширинах высота составляет 140 / около 140.4 / 150 px. Свободная высота не зависит от момента загрузки картинки.

Изображения отображаются через `object-fit: cover`. Небольшой выход изображения за границы карточки скрывает встроенные поля; `object-position: 45% 50%` сохраняет подписи и основные иллюстрации. Premium использует собственное положение и меньшую вертикальную обрезку, чтобы оставить корону целой. Небольшой запас исходного фона над короной сохранён намеренно.

Обрезка выполнена **неразрушающе через CSS-окно**, а не повторным кодированием WebP: все четыре файла, их SHA-256, разрешение и качество побайтно совпадают с `6ad36df`. Это удаляет избыточные поля при отображении без растягивания и дополнительной потери качества. Новые изображения не генерировались. Текстовые слои не добавлялись.

Порядок и действия прежние: подготовка к экзаменам → тесты; конспекты → конспекты; повторение ошибок → честное информационное окно недоступности; Premium → существующее окно Premium. Scroll-snap, край следующего баннера, обычная вертикальная прокрутка, safe-area и Telegram BackButton не изменены.
