# ANATOMAI UI 5.2 — Liquid Glass, Zoom Lock & Simplified Tests

## Основа

Ветка `feature/anatomai-ui-5.2` создана от `feature/anatomai-tests-2`, коммит `9cd04f5`. PR #1, #2 и #3 на момент начала работы открыты и не объединены; main остаётся на `71f1392`. Основа включает Core 5.0, Layout 5.0.1 и Tests 2.0. Новый Draft PR направлен в ветку PR #3, чтобы показать только изменения 5.2.

В сообщении доступно текстовое ТЗ; скриншотов/видеозаписи для точного визуального сопоставления не было. Выполнена визуальная проверка локальных browser screenshots главной, прокрутки и ответа.

## Изменения

- Главная: удалены SVG-фигура, декоративные окружности и связанные стили. Сохранены название, заголовок, описание и CTA. Статические «5 дней подряд» и «+120 XP» удалены: достоверного источника для них нет. Тестовые данные не изменены.
- Уведомления: компактный SVG-колокольчик, кнопка 44×44px с существующей мягкой границей; ложный красный индикатор удалён. Нового экрана уведомлений нет.
- Навигация: четыре существующие вкладки с SVG-иконками и aria-current. Плавающая капсула высотой 64px, радиус 28px, края 12px + горизонтальные safe insets, полупрозрачная белая поверхность, blur(20px) saturate(180%), тонкая граница и мягкая тень. Активная вкладка имеет лёгкую голубую подсветку. Предусмотрены непрозрачнее fallback при отсутствии blur и reduced-motion.
- Капсула расположена на max(8px, effective bottom inset) выше низа viewport; внутри неё дополнительного системного inset нет. Контент прокручивается позади панели. В конце scrollport резервируется ровно `64px + bottom offset + 12px`, поэтому последний блок доступен над капсулой. В тестовом потоке резерв не применяется, нижняя safe-area учитывается по схеме 5.0.1.
- Обучение: нажатие на ответ сразу вызывает существующий confirmAnswer. Правильная карточка зелёная, ошибочная выбранная — красная, остальные нейтральные. Ответы disabled после проверки, повторное нажатие не меняет счёт. «Проверить ответ» удалена; «Далее»/«Завершить тест» появляется после проверки. Автоперехода нет. Объяснение отображается только при непустом тексте данных.
- Экзамен сохраняет выбор/смену ответа и проверку в конце; правильность не раскрывается. Hook, подсчёт, данные, результаты, история и Telegram BackButton не переписаны.

## Zoom lock и ограничения доступности

Viewport: `width=device-width, initial-scale=1, maximum-scale=1, minimum-scale=1, user-scalable=no, viewport-fit=cover`.

В shell применяется `touch-action:pan-x pan-y`; интерактивные элементы сохраняют manipulation. Это допускает обычную вертикальную/горизонтальную прокрутку и нажатия, ограничивая browser zoom. Шрифт поиска остаётся 16px, text-size-adjust — 100%.

`attachZoomLock` подключается к DOM-узлу shell через React effect. Отменяются только:

- gesturestart/gesturechange;
- touchstart/touchmove с несколькими пальцами;
- default dblclick;
- второе неподвижное touchend с коротким интервалом на неинтерактивном контенте.

Однопальцевые touchmove и click не отменяются. Кнопки, ссылки, input и другие интерактивные элементы исключены из touchend-guard, чтобы не потерять обычные клики и focus. Скролл/свайп определяется по движению и не трактуется как double tap. Нет глобального document touchmove.preventDefault. Все семь listeners удаляются в cleanup; StrictMode cleanup/re-init безопасен. Защита адаптера от reflow при pinch из 2.0 сохранена на случай, если host всё же разрешит жест.

Это **best effort**, а не гарантия полного запрета на любом iPhone. Web-сайт не управляет нативной конфигурацией Telegram WKWebView (`ignoresViewportScaleLimits`); iOS/Safari/настройки доступности могут игнорировать viewport-ограничения или обрабатывать жест вне DOM. Системный Accessibility Zoom не контролируется веб-приложением. Проверить конфигурацию встроенного WebView Telegram из этого окружения невозможно.

По явному требованию 5.2 введено более жёсткое ограничение, чем в Tests 2.0. Оно снижает доступность для пользователей, которым нужно увеличение текста/интерфейса. Этот компромисс нужно учитывать при приёмке; системное масштабирование ОС не обещается отключить.

npm test
npm run build

- Полные прохождения обучения и экзамена: мгновенная проверка, блокировка повторного изменения, серия/пропуск, отсутствие экзаменационных подсказок, результаты 3/1/1 и 60%, разбор ошибок, повтор и reduced-motion.
- Тестовые данные, contracts/types и useTestSession не менялись. Backend, авторизация, MEDEXA и production не затрагивались; merge/deploy не выполнялись.

## Приёмка на iPhone

Настоящий iPhone, Telegram iOS и Safari не запускались. Chromium с mock SDK и синтетические events не доказывают запрет нативного pinch/double-tap в WKWebView. WebKit окружению недоступен из-за системных библиотек. Keyboard/reopen проверены моделированием resize/reload.

На устройстве проверить pinch и double-tap на тексте/карточках/кнопках, одиночные нажатия, вертикальный скролл и горизонтальный свайп, клавиатуру и visualViewport, fullscreen/expanded, Home Indicator, прозрачность капсулы/читаемость и переключение вкладок. Дальнейшие ограничения старой истории/таймера/хранения и незавершённые разделы не входили в эту задачу.
